# Palace Countdown

Motivator: Challenge (mastering a repeatable escape route).

## Mechanic

Escape through ten randomly chosen rooms (repeats allowed). Choose **Jump**, **Climb**, or **Run** to get past
each obstacle. Each room has one successful action; the obstacle description
shows the obstacle: a pit or gap calls for Jump, a high ledge for Climb,
and a closing gate for Run. The three buttons are shuffled in each room. Use a mouse, touch, or Tab and Enter/Space.

Set **Time limit**, then press **Begin escape**. With the clock on, you have
3 seconds per room, shown as a shrinking bar. Each new room resets the timer
to 3 seconds. Time reaching zero counts as a fall and ends the run.
A wrong choice still costs 5 seconds, so with this shorter timer a wrong
choice also causes a fall. With the clock off, there is no countdown or
time penalty: try again until you pass. The clock starts only when you begin.

Changing the toggle resets the run and waits for you to begin again.
**Restart escape** starts a fresh run with the current setting. Replay the
game with both settings, then use the reflection box to compare how
you felt.

## Dynamic

One playtester, a first-time player, tried the clock ON, then OFF. With the clock on, the shuffled button order caught him off guard and he nearly ran out of time in 3 of 10 rooms, but he still escaped on his first run. With the clock off he slowed down and cleared every room easily. The time limit changed his pace and created a few close calls, but not failure: each obstacle always looks the same, so after a few rooms he was recognizing pictures rather than reading the danger.

## Aesthetic

He described clock ON as "reasonable" and clock OFF as "stupidly easy." The clock added mild pressure, not the triumph-over-adversity the motivator promises. His suggestion: vary how each obstacle looks so the player has to read and decide under time pressure, not just recognize a familiar drawing.

## Sources

From the Challenge and mastery section of the course note:

- Time pressure as a dynamic of Challenge: "Time pressure and opponent play (Hunicke et al. 2004, p. 3)."
- Speeded responses as a mechanic: "Score-keeping and speeded responses, which set goals beyond the goal (Malone 1980, p. 66)."

Built with Codex. Codex's first version used a single 60-second clock and a fixed answer pattern; I changed it to a 3-second per-room timer with obstacles in random order and shuffled buttons after the 60-second version left more than half the time unused. Inspired by Prince of Persia (Broderbund, 1989); all art and text are original.
