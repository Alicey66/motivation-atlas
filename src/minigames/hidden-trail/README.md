# Hidden Trail

Motivator: discovery. Author: raycarllei. Mode comparison pending.

## Mechanic

Find three beacons marked B, then walk to E using buttons, arrow keys, or WASD.
Walls block movement. Hide unexplored tiles reveals your surroundings as you
move; turn it off to inspect the whole map. Small numbers count visits in
both modes, distinguishing tiles you walked on from neighbors you only saw.
The switch preserves progress. Restart clears visits on the same map.
